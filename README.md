# Rode Medical Centre

Bilingual (Arabic / English) website for **مجمع رود الشامل الطبي العام — Rode Medical Centre** in Madinah.

## Features

- RTL Arabic by default, with one-click English toggle
- Home, Services, About, and Contact pages
- Call, WhatsApp, Google Maps, and Linktree actions
- Brand colors from the clinic logo (cyan → royal blue, lime green)
